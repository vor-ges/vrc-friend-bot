
# vrc-friend-bot

VRChatのフレンドの活動状況を監視し、Discordへの通知やゲーム内活動統計の記録を行うDiscord Botです。Discordへの通知登録の有無にかかわらず、VRChat上の全フレンドを統計収集の対象とします。

[English](README.md)

## コンセプト

このプロジェクトは、ある友人の何気ない疑問から始まりました。

「フレンドは普段、何時ごろにオンラインになっているのだろう？」

[vrc-meikan](https://vrc-meikan.com/) の普及に伴い、その友人は多くのユーザーとフレンドになりました。しかし、その中にはまだ会ったことのない人も少なくありませんでした。

そこで、フレンドが普段どの時間帯にログインしているのかを知りたいと考えました。

もし、あるフレンドが予想より早い時間帯にログインする傾向があると分かれば、自分も早めにログインすることで、会える可能性を高められるかもしれません。

そのアイデアをきっかけに、このBotの開発が始まりました。

## 概要

`vrc-friend-bot` は、VRChatのフレンドを監視し、ゲーム内での活動状況・居場所・ステータスに変化があった際にDiscordへ通知するBotです。

また、Discordへの通知登録状況とは独立して、VRChat上の全フレンドのゲーム内活動を記録します。

これにより、Discordへの通知登録を解除した後も、そのユーザーがVRChat上のフレンドである限り、活動統計の収集を継続できます。

長期的な記録を行うため、24時間稼働できるサーバーでの運用を推奨します。

現在はOracle Cloud上のUbuntuサーバーで稼働しています。

## 主な機能

- **オンライン通知** — 通知登録したフレンドがVRChatにゲーム内ログインした際に通知します。
- **オフライン通知** — ゲーム内でオンラインを検知していた通知登録済みフレンドがログアウトした際に通知します。
- **居場所の変更通知** — 通知登録したフレンドが別のワールドやインスタンスへ移動した際に通知します。
- **ワールド情報の表示** — ワールド名、インスタンスタイプ、リージョン、プレイヤー数などを取得できる範囲で表示します。
- **インスタンスオーナー情報** — インスタンスのオーナー名を取得します。VRChatグループのインスタンスであれば、グループ名も取得します。
- **ステータス変更通知** — 通知登録したフレンドのVRChatステータスやステータス説明文が変更された際に通知します。
- **フレンド専用チャンネル** — Discordへの通知登録を行ったフレンドごとに専用テキストチャンネルを作成します。
- **フレンド管理** — スラッシュコマンドからDiscordへの通知登録・解除・一覧表示を行えます。
- **フレンドの候補選択** — オートコンプリートからVRChatのフレンドを表示名で検索・選択できます。
- **削除確認** — 通知登録の解除前に確認画面を表示し、誤操作を防止します。
- **登録一覧のページ切り替え** — 登録人数が多い場合、一覧をページ単位で表示します。
- **ログイン統計** — Discordへの通知登録状況に関係なく、VRChat上の全フレンドのゲーム内ログイン時刻・回数・滞在時間を記録します。
- **全フレンドの活動記録** — Discordへの通知登録と独立して、VRChat上のフレンド全員の活動を収集します。
- **フレンド一覧の自動同期** — Bot起動時、WebSocket再接続時、6時間ごとにVRChatのフレンド一覧を同期します。
- **フレンド別統計** — Discordへの通知登録がないフレンドについても、個別の活動統計を確認できます。
- **統計対象の選択** — `/stats` のオートコンプリートから、登録済み・未登録・削除済み・フレンド解除済みのユーザーを選択できます。
- **活動傾向の分析** — 時間帯別のログイン頻度、ゲーム内滞在時間、ステータス別の使用割合を表示します。
- **統計データの保持** — Discordへの通知登録解除やVRChat上でのフレンド解除後も、過去の統計データを保持します。
- **表示名の自動更新** — VRChat上でフレンドの表示名が変更された場合、保存されている名前も更新します。
- **メンション設定** — オンライン通知時のDiscordメンションを全体またはフレンドごとに設定できます。
- **言語切り替え** — `/lang` コマンドでBotの表示言語を日本語・英語に切り替えられます。
- **設定の永続化** — 言語設定やメンション設定をデータベースに保存し、Botの再起動後も維持します。

### 通知対象と統計収集対象の違い

このBotでは、Discordへの通知登録とVRChatの活動統計収集を独立して管理しています。

| 機能 | VRChat上の全フレンド | Discord通知登録済みフレンド |
|---|---|---|
| 活動統計 | ○ | ○ |
| ログイン履歴 | ○ | ○ |
| ゲーム内滞在時間 | ○ | ○ |
| ステータス使用割合 | ○ | ○ |
| オンライン通知 | × | ○ |
| オフライン通知 | × | ○ |
| 居場所の変更通知 | × | ○ |
| ステータス変更通知 | × | ○ |
| 専用Discordチャンネル | × | ○ |

`/remove` で通知登録を解除しても、Discordへの通知が停止するだけで、VRChat上のフレンドである限り活動統計の収集は継続されます。

VRChat上でBotアカウントとのフレンド関係が解除された場合、自動的な活動収集は停止しますが、それまでに記録された統計データは保持されます。

### フレンド一覧の自動同期

VRChatのフレンド一覧を定期的に取得し、活動記録を最新の状態に保ちます。

同期は以下のタイミングで実行されます。

- Botの起動時
- VRChat WebSocketの再接続時
- 6時間ごとの定期同期

オンライン・オフライン双方のフレンドを取得し、1回のリクエストにつき最大100件ずつページングして取得します。

同期時には、フレンド情報や現在のゲーム内状態を更新し、保存済みの活動履歴との整合性を確認します。

なお、同期処理自体によってDiscord通知が送信されることはありません。

WebSocketの切断中に発生した状態変化についても、再接続後の同期によって補正します。

### ゲーム内活動とWeb活動の違い

VRChatでは、ゲーム内へのログインとWebサイト上での活動は別のイベントとして扱われます。

このBotはゲーム内活動のみを監視対象としています。

- VRChatのWebサイトにログインしただけでは、オンライン通知は送信されません。
- Webサイト上だけの活動は、ゲーム内ログインとして記録されません。
- ゲーム内でオンラインを検知した通知登録済みフレンドがVRChatからログアウトした際に、オフライン通知を送信します。

## 動作要件

- Python
- Discord Botアカウント
- VRChatアカウント
- `requirements.txt` に記載されたPythonパッケージ

## 導入方法

### 1. Discord Botの作成

1. Discord Developer PortalからBotアプリケーションを作成します。
2. 必要な権限を設定し、BotをDiscordサーバーに招待します。
3. 設定に必要な各種IDを準備します。

### 2. 環境変数の設定

`.env.example` をテンプレートとして、`.env` ファイルを作成します。

以下の環境変数を設定してください。

| 環境変数 | 説明 |
|---|---|
| `DISCORD_TOKEN` | Discord Botのトークン |
| `GUILD_ID` | DiscordサーバーのID |
| `MAIN_CHANNEL_ID` | メインチャンネルのID |
| `OWNER_ID` | Bot所有者のDiscordユーザーID |
| `VRC_USERNAME` | VRChatのユーザー名 |
| `VRC_PASSWORD` | VRChatのパスワード |
| `VRC_USER_AGENT` | VRChat APIリクエストで使用するUser-Agent |
| `STATS_TZ` | 統計表示に使用するタイムゾーン（任意、省略時は `Asia/Tokyo`） |

### 3. 依存パッケージのインストール

Pythonをインストールしたうえで、以下を実行します。

```bash
pip install -r requirements.txt
```

### 4. Botの起動

必要なファイルがすべて同じディレクトリに配置されていることを確認し、以下のコマンドで起動します。

```bash
python bot.py
```

## 使い方

### 1. フレンド管理

設定済みのDiscordサーバーのメインチャンネルで、以下のスラッシュコマンドを使用します。

| コマンド | 説明 |
|---|---|
| `/add target:` | VRChatのフレンドをDiscord通知対象に登録します。 |
| `/remove target:` | Discord通知対象から解除します。 |
| `/list` | Discord通知対象のフレンド一覧を表示します。 |

#### `/add`

VRChatのフレンドをDiscord通知対象に登録します。

- オートコンプリート候補からフレンドを選択できます。
- 表示名による検索に対応しています。
- VRChatのプロフィールURLまたはユーザーIDを直接指定することもできます。
- 登録したフレンドごとに、`VRC-Friends` カテゴリの下に専用テキストチャンネルが作成されます。

現在VRChat上でフレンドになっており、まだDiscord通知登録されていないユーザーが候補に表示されます。過去に通知登録を解除したユーザーも再登録できます。

自動同期によって既に情報が保存されているフレンドの場合、追加のユーザー情報API呼び出しを省略できます。

指定したユーザーがVRChat上でフレンドではない場合でも通知登録自体は可能ですが、通知が届かない可能性があることを警告します。

#### `/remove`

Discord通知対象からフレンドを解除します。

- オートコンプリート候補から登録済みフレンドを選択できます。
- 表示名やユーザーIDで候補を絞り込めます。
- 同名ユーザーを区別するため、候補にはUIDの末尾6文字が表示されます。
- 解除前に確認画面が表示されます。
- 確認画面は60秒でタイムアウトします。

解除しても専用チャンネルや過去のメッセージ履歴は削除されません。

**重要：** `/remove` はDiscord通知を停止するだけです。対象ユーザーがVRChat上でフレンドである限り、活動統計の収集は継続されます。

#### `/list`

Discord通知対象のフレンド一覧を表示します。

以下のオプションを利用できます。

| オプション | 説明 |
|---|---|
| `show_uid` | UIDを一覧に表示します。 |
| `include_removed` | 解除済みの通知登録も一覧に含めます。 |

登録人数が多い場合は、ページ切り替えボタンで一覧を閲覧できます。

一覧にはオンライン通知のメンション設定状態も表示されます。

### 2. ログイン統計

以下のコマンドを使用します。

```text
/stats
```

実行するチャンネルや指定するオプションによって、表示される統計が変わります。

| 使用方法 | 表示内容 |
|---|---|
| メインチャンネルで `/stats` | 現在Discord通知登録されている全フレンドの統計 |
| フレンド専用チャンネルで `/stats` | 該当するフレンドの統計 |
| `/stats who:` | Discord通知登録状況に関係なく、指定したフレンドの統計 |
| `/stats days:` | 指定した日数に限定した統計 |

`who` オプションでは、オートコンプリートから既知のVRChatフレンドや過去に登録したユーザーを選択できます。

以下のユーザーが対象になります。

- 現在Discord通知登録されているフレンド
- 過去に通知登録を解除したフレンド
- Discord通知登録されていないVRChatフレンド
- Botアカウントとのフレンド関係が解除されたが、過去の記録が残っているユーザー

表示名またはUIDで対象を特定できます。

個別のフレンドを指定した場合、そのフレンドの収集開始日時を統計期間の開始として使用します。

`days` オプションでは1〜365日の範囲で集計期間を指定できます。省略した場合は、記録されている全期間が対象になります。

統計には以下の情報が含まれます。

- 時間帯別のログイン頻度
- ゲーム内ログイン回数
- ゲーム内滞在時間
- VRChatステータスの使用割合
- 複数のフレンドを集計した場合のフレンド別統計

**注意：** 初めて状態を取得した時点ですでにゲーム内にいたフレンドは、既存セッションの復元として記録される場合があります。この場合、ゲーム内滞在時間には反映されますが、新規ログイン回数には加算されません。

### 3. メンション設定

`/mention` コマンドを使用して、オンライン通知時のDiscordメンションを切り替えられます。

| コマンド | 説明 |
|---|---|
| `/mention state:on` | オンライン通知時のメンションを有効にします。 |
| `/mention state:off` | オンライン通知時のメンションを無効にします。 |
| `/mention state:reset` | フレンド別の設定を解除して全体設定に戻します。 |

設定するチャンネルによって対象が変わります。

- **メインチャンネル：** 全体設定を変更します。
- **フレンド専用チャンネル：** 該当するフレンドの個別設定を変更します。

フレンド別の設定がある場合は、全体設定よりも個別設定が優先されます。

`reset` はフレンド専用チャンネルでのみ使用できます。

初期設定ではメンションが有効になっています。

### 4. 言語切り替え

`/lang` コマンドを使用して、Botの表示言語を変更できます。

| コマンド | 説明 |
|---|---|
| `/lang code:ja` | 表示言語を日本語に変更します。 |
| `/lang code:en` | 表示言語を英語に変更します。 |

言語設定はBot全体で共有され、データベースに保存されます。

選択した言語はBotを再起動しても維持されます。

初期設定は日本語です。

**注意：** 翻訳が用意されているメッセージのみ言語が切り替わります。翻訳が用意されていない文章は日本語で表示されます。

## 注意事項

- 管理・統計・言語切り替え・メンション設定の各コマンドを使用できるのは、設定されたBot所有者のみです。
- フレンド管理コマンドは、設定されたメインチャンネルで使用する必要があります。
- 統計コマンドはメインチャンネルまたはフレンド専用チャンネルで使用してください。
- 自動同期および継続的な活動収集には、BotのVRChatアカウントが対象ユーザーとフレンドである必要があります。
- VRChat上でフレンドではないユーザーもDiscord通知対象に登録できますが、通知が届かない可能性があります。
- VRChat APIの利用には認証要件やレート制限があります。
- VRChatの初回認証時には、二要素認証（2FA）が必要になる場合があります。
- 活動統計の収集はBotが対象フレンドを初めて検知した時点から開始されます。それ以前の活動履歴を遡って取得することはできません。
- 統計はBotが受信したイベントと状態同期に基づくものであり、VRChat公式の活動履歴ではありません。
- ログイン統計にはゲーム内活動のみが含まれます。Webサイト上だけの活動は集計対象外です。
- フレンド一覧を完全に取得できなかった場合に、大量のユーザーを誤ってフレンド解除済みと判定しないための安全策を設けています。

## セキュリティ

`.env` ファイルには、Discord BotのトークンやVRChatの認証情報など、機密情報が含まれています。

- `.env` ファイルを他人に共有したり、公開したりしないでください。
- Gitのバージョン管理対象から `.env` を除外してください。
- 認証情報を公開せずに設定例を共有する場合は、`.env.example` を使用してください。
