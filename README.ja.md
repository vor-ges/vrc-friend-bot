# vrc-friend-bot

VRChatのフレンドのオンライン状況を監視し、活動状況の通知やログイン統計の記録を行うDiscord Botです。

[English](README.md)

## コンセプト

このプロジェクトは、ある友人の何気ない疑問から始まりました。

「フレンドは普段、何時ごろにオンラインになっているのだろう？」

[vrc-meikan](https://vrc-meikan.com/) の普及に伴い、その友人は多くのユーザーとフレンドになりました。しかし、その中にはまだ会ったことのない人も少なくありませんでした。

そこで、フレンドが普段どの時間帯にログインしているのかを知りたいと考えました。

もし、あるフレンドが予想より早い時間帯にログインする傾向があると分かれば、自分も早めにログインすることで、会える可能性を高められるかもしれません。

そのアイデアをきっかけに、このBotの開発が始まりました。

## 概要

`vrc-friend-bot` は、登録したVRChatのフレンドを監視し、ゲーム内での活動状況・居場所・ステータスに変化があった際にDiscordへ通知するBotです。

また、ログイン時刻やゲーム内での活動時間を記録し、フレンドの活動傾向を長期的に分析できます。

継続的な記録を行うため、24時間稼働できるサーバーでの運用を推奨します。

現在はOracle Cloud上のUbuntuサーバーで稼働しています。

## 主な機能

- **オンライン通知** — 登録したフレンドがVRChatにゲーム内ログインした際に通知します。
- **オフライン通知** — ゲーム内でオンラインを検知していたフレンドがログアウトした際に通知します。
- **居場所の変更通知** — フレンドが別のワールドやインスタンスへ移動した際に通知します。
- **ワールド情報の表示** — ワールド名、インスタンスタイプ、リージョン、プレイヤー数などを取得できる範囲で表示します。
- **インスタンスオーナー情報** — インスタンスのオーナー名を取得します。VRChatグループのインスタンスであれば、グループ名も取得します。
- **ステータス変更通知** — フレンドのVRChatステータスやステータス説明文が変更された際に通知します。
- **フレンド専用チャンネル** — 登録したフレンドごとにDiscordの専用テキストチャンネルを作成します。
- **フレンド管理** — スラッシュコマンドからフレンドの登録・解除・一覧表示を行えます。
- **ログイン統計** — ゲーム内のログイン時刻を記録し、活動統計を算出します。
- **活動傾向の分析** — 時間帯別のログイン頻度や、ゲーム内滞在時間に基づくステータス使用割合を表示します。
- **フレンド別統計** — メインチャンネルでは登録中の全フレンド、専用チャンネルでは該当フレンドの統計を表示します。
- **言語切り替え** — `/lang` コマンドでBotの表示言語を日本語・英語に切り替えられます。
- **言語設定の永続化** — 選択した言語をデータベースに保存し、Botの再起動後も設定を維持します。

### ゲーム内活動とWeb活動の違い

VRChatでは、ゲーム内へのログインとWebサイト上での活動は別のイベントとして扱われます。

このBotはゲーム内活動のみを監視対象としています。

- VRChatのWebサイトにログインしただけでは、オンライン通知は送信されません。
- Webサイト上だけの活動は、ゲーム内ログインとして記録されません。
- ゲーム内でオンラインを検知したフレンドがVRChatからログアウトした際に、オフライン通知を送信します。

## 動作要件

- Python
- Discord Botアカウント
- VRChatアカウント
- `requirements.txt` に記載されたPythonパッケージ

## 導入方法

### 1. Discord Botの作成

1. Discord Developer PortalからBotアプリケーションを作成します。
2. 必要な権限を設定し、BotをDiscordサーバーに招待します。
3. 設定に必要な各種IDを準備します。

### 2. 環境変数の設定

`.env.example` をテンプレートとして、`.env` ファイルを作成します。

以下の環境変数を設定してください。

| 環境変数 | 説明 |
|---|---|
| `DISCORD_TOKEN` | Discord Botのトークン |
| `GUILD_ID` | DiscordサーバーのID |
| `MAIN_CHANNEL_ID` | メインチャンネルのID |
| `OWNER_ID` | Bot所有者のDiscordユーザーID |
| `VRC_USERNAME` | VRChatのユーザー名 |
| `VRC_PASSWORD` | VRChatのパスワード |
| `VRC_USER_AGENT` | VRChat APIリクエストで使用するUser-Agent |

### 3. 依存パッケージのインストール

Pythonをインストールしたうえで、以下を実行します。

```bash
pip install -r requirements.txt
```

### 4. Botの起動

必要なファイルがすべて同じディレクトリに配置されていることを確認し、以下のコマンドで起動します。

```bash
python bot.py
```

## 使い方

### 1. フレンド管理

設定済みのDiscordサーバーで、以下のスラッシュコマンドを使用します。

| コマンド | 説明 |
|---|---|
| `/friend add url:` | VRChatのプロフィールURLまたはユーザーIDを指定してフレンドを登録します。 |
| `/friend remove target:` | 登録済みのフレンドを解除します。 |
| `/friend list` | 登録済みのフレンド一覧を表示します。 |

登録したフレンドごとに、`VRC-Friends` カテゴリの下に専用テキストチャンネルが作成されます。

フレンドの登録を解除しても、チャンネルや過去のメッセージ履歴は削除されません。後から再登録することもできます。

### 2. ログイン統計

以下のコマンドを使用します。

```text
/stats
```

コマンドを実行するチャンネルによって、表示される統計が変わります。

- **メインチャンネル：** 現在登録されている全フレンドの統計を表示します。
- **フレンド専用チャンネル：** 該当するフレンドの統計を表示します。

`days` を指定すると、最大365日までの期間を指定して統計を表示できます。

`days` を省略した場合は、記録されている全期間が対象になります。

統計には以下の情報が含まれます。

- 時間帯別のログイン頻度
- ゲーム内ログイン回数
- ゲーム内滞在時間
- VRChatステータスの使用割合

### 3. 言語切り替え

`/lang` コマンドを使用して、Botの表示言語を変更できます。

| コマンド | 説明 |
|---|---|
| `/lang code:ja` | 表示言語を日本語に変更します。 |
| `/lang code:en` | 表示言語を英語に変更します。 |

言語設定はBot全体で共有され、データベースに保存されます。

選択した言語はBotを再起動しても維持されます。

初期設定は日本語です。

**注意：** 翻訳が用意されているメッセージのみ言語が切り替わります。翻訳が用意されていない文章は日本語で表示されます。

## 注意事項

- 管理・統計・言語切り替えの各コマンドを使用できるのは、設定されたBot所有者のみです。
- フレンド管理コマンドは、設定されたメインチャンネルで使用する必要があります。
- 監視対象のユーザーとBotのVRChatアカウントがフレンドである必要があります。フレンドでない場合、通知を受け取れない可能性があります。
- VRChat APIの利用には認証要件やレート制限があります。
- VRChatの初回認証時には、二要素認証（2FA）が必要になる場合があります。
- ログイン統計はBotが記録した活動に基づきます。記録開始後に追加されたフレンドは、登録された時点以降の活動が集計対象になります。
- ログイン統計にはゲーム内活動のみが含まれます。Webサイト上だけの活動は集計対象外です。

## セキュリティ

`.env` ファイルには、Discord BotのトークンやVRChatの認証情報など、機密情報が含まれています。

- `.env` ファイルを他人に共有したり、公開したりしないでください。
- Gitのバージョン管理対象から `.env` を除外してください。
- 認証情報を公開せずに設定例を共有する場合は、`.env.example` を使用してください。
